楊梅高中紅土藝術空間 網站 — 使用說明
==========================================

【開啟網站】
  雙擊「開啟網站.bat」或直接開啟 index.html（不需網路、不需伺服器）。
  若要放到學校網站，把整個「楊梅高中紅土藝術空間」資料夾上傳即可
  （原始大圖資料夾「紅土藝術空間」不必上傳，網站只使用 img/ 內的轉檔圖片）。

【新增期別】
  1. 在「紅土藝術空間」資料夾新增期別資料夾，例如：11502(某某創作展)
     期別代碼 = 民國年(3碼) + 當年第幾檔(2碼)。
  2. 圖片依規則命名後放入：
       11502(某某創作展)海報1.JPG
       11502(某某創作展)邀請卡正面1.JPG / 邀請卡背面1.JPG
       11502(某某創作展)小卡正面1.JPG   / 小卡背面1.JPG
     同一類有多張時，流水號用 2、3、4…
  3. 雙擊「更新網站.bat」。程式會自動：
       - 轉成網頁用 WebP 圖片與縮圖（img/）
       - 用 Windows 內建 OCR 辨識圖上文字，供全文檢索
       - 自動判斷展覽類別、推測展期、擷取主題色
     只處理新增或修改過的圖片；刪除的圖片也會同步移除。
  需求：Python 3 與 Pillow（pip install pillow）。

【補充或修正資料】 data/meta.json
  以期別代碼為鍵，可填入：
    "title"    展名          "artist"   藝術家
    "period"   展期（例如 2026/05/18 – 2026/06/05，會取代自動辨識結果）
    "intro"    展覽介紹      "category" 個展/聯展/班級展/校友展/主題特展/講座
    "color"    主題色（例如 #9c65b9）
  範例：
    { "11501": { "artist": "羅桂蘭", "intro": "以四季為題的油畫創作…" } }
  修改後再執行一次「更新網站.bat」。

【檔案結構】
  index.html / style.css / app.js   網站程式
  assets/校徽.jpg、assets/logo.svg  校徽與紅土藝術空間標誌
  data/exhibitions.js               自動產生的展覽資料（勿手動修改）
  data/meta.json                    手動補充資料
  data/ocr/                         文字辨識快取
  tools/build.py、tools/ocr.ps1     建置程式
